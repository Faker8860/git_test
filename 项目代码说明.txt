================================================================================
                    量化交易系统 — 项目代码说明文档
================================================================================

【项目概述】
本项目是一套完整的加密货币量化交易系统，支持币安（Binance）U本位永续合约交易。
系统架构：Web管理面板 + 自主交易引擎 + TradingView信号桥接 + 数据监控。

部署环境：阿里云 ECS（Ubuntu 22.04），公网地址 http://47.76.187.153:8000
本地开发：Windows 11 + Python 3.12


================================================================================
一、核心交易引擎
================================================================================

1. strategy_bot.py  — 自主交易机器人（主力策略）
   - 作用：基于技术指标的自主交易引擎，支持多币种、多策略独立运行
   - 策略：TEMA趋势跟随（OCC Strategy v8.13）和 Volty Expan Close（波动性突破）
   - 运行方式：python strategy_bot.py（后台常驻进程，通过 Web面板启动/停止）
   - 主要功能：
     * 多币种并行监控（从 strategies.json 读取币种列表）
     * 每个币种可独立配置策略类型和参数
     * K线数据拉取、指标计算、信号判断
     * 自动开仓/平仓/止损（止盈）
     * 仓位管理和风控
     * 信号延迟确认（防止假突破）
     * 资金费率检测（极值提醒）
   - 输入：.env（全局参数）、strategies.json（币种级策略覆盖）
   - 输出：strategy_state.json（状态持久化）、strategy.log（运行日志）、trades.json（交易记录）

2. bot_server.py  — TradingView → 币安 信号桥接器
   - 作用：接收 TradingView 告警 Webhook，解析后自动在币安下单
   - 框架：FastAPI + uvicorn
   - 运行方式：uvicorn bot_server:app --host 0.0.0.0 --port 8000（通常由 gui.py 启动）
   - 主要功能：
     * 接收 TradingView Webhook POST 请求
     * HMAC 签名验证（可选，WEBHOOK_SECRET）
     * 解析 TV 告警中的订单信息（币种、方向、金额）
     * 自动转换交易对格式（ETHUSDT → ETH/USDT:USDT）
     * 设置杠杆、计算合约张数
     * 市价开仓 + 自动止损挂单
     * 最大下单金额限制、最小下单金额过滤
     * 交易记录保存到 trades.json
   - 输入：.env（API密钥、风控参数）、TradingView告警JSON
   - 输出：bot.log（运行日志）、trades.json（交易记录）


================================================================================
二、Web 管理面板
================================================================================

3. web_ui.py  — 主控面板（Web UI v3）★核心文件
   - 作用：一站式 Web 管理后台，实时数据仪表盘 + 策略配置 + 监控 + 日志
   - 框架：Python http.server（ThreadingHTTPServer 多线程）
   - 端口：8000（通过 .env 中 UI_PORT 配置）
   - 页面功能（6个Tab）：
     * 仪表盘：账户余额、持仓列表、资金费率、交易历史、订单簿（全部币安实时API）
     * 策略配置：添加/编辑/删除每币种策略覆盖，保存后自动重启机器人
     * 数据监控：K线图表（Chart.js）、多币种行情表
     * 资产分析：胜率、盈亏比、交易偏好（Chart.js饼图/柱状图）
     * 系统日志：strategy.log 实时查看、按级别筛选
     * 设置中心：API密钥管理、服务控制
   - 关键改进（v3）：
     * ThreadingHTTPServer 多线程处理并发请求
     * ThreadPoolExecutor 并行获取币安API数据（5s超时保护）
     * ccxt 全局超时 10s，单调用独立线程超时
     * 所有 API 路由 try/except 保护，不会崩溃
     * 跨平台兼容（Windows/Linux 进程管理自适应）
     * JSON 解析安全防护（_parse_json 容错）
   - 输入：.env、strategies.json、trades.json、watchlist.json、strategy_state.json、strategy.log
   - 输出：HTML页面、JSON API（20+ 接口）

4. dashboard.py  — 简易仪表盘（Legacy v2）
   - 作用：旧版独立仪表盘，简单的 HTML 页面，10秒自动刷新
   - 端口：8080
   - 运行方式：python dashboard.py
   - 主要功能：
     * HTML 页面渲染，基础数据展示
     * 读 trades.json 展示交易记录和盈亏统计
     * 读 strategy_state.json 展示策略运行状态
     * 读 strategy.log 展示最新日志
     * 简单的仓位/收益计算
   - 说明：已基本被 web_ui.py v3 取代，仅作备用


================================================================================
三、桌面客户端
================================================================================

5. gui.py  — 桌面控制面板（Tkinter GUI）
   - 作用：Windows 桌面图形界面，用于控制 bot_server.py 服务
   - 框架：Tkinter + uvicorn
   - 运行方式：python gui.py（启动后弹出窗口 + 后台服务）
   - 主要功能：
     * 启动/停止 bot_server.py（端口 8000）
     * 设置下单金额、止损比例、杠杆倍数
     * 实时日志显示
     * 服务运行状态指示
     * API Key 配置
   - 说明：本地面向 TradingView Webhook 场景，不用于服务器部署


================================================================================
四、配置文件
================================================================================

6. .env  — 主配置文件（生产环境）
   - 内容：币安 API Key/Secret、交易参数、策略参数、端口配置
   - 主要字段：
     * BINANCE_API_KEY / BINANCE_SECRET_KEY：币安 API 密钥
     * SYMBOLS：交易币种（逗号分隔，如 ETHUSDT,BTCUSDT）
     * LEVERAGE：杠杆倍数（默认3x）
     * POSITION_PCT：仓位占比（默认80%）
     * STOP_LOSS_PCT：止损比例（默认5%）
     * MA_TYPE / MA_LEN / CROSS_MULT / DELAY_MINUTES：均线策略参数
     * STRATEGY_TYPE：策略类型（TEMA/VOLTY）
     * MAX_ORDER_USDT / MIN_ORDER_USDT：风控额度上下限
     * UI_PORT：Web面板端口（默认8000）

7. .env.example  — 配置文件模板
   - 作用：供新环境参考的配置模板，含所有字段及注释说明

8. strategies.json  — 币种级策略覆盖配置
   - 作用：为不同币种单独配置策略参数，优先级高于 .env 全局配置
   - 格式：JSON数组，每个元素含 symbol + 完整策略参数
   - 示例：
     [
       {"symbol":"ETHUSDT", "strategyType":"VOLTY", "timeframe":30, ...},
       {"symbol":"ZECUSDT", "strategyType":"TEMA", "timeframe":15, ...}
     ]
   - 说明：已配置的币种自动加入交易列表，不需在 .env 的 SYMBOLS 中重复

9. trades.json  — 交易历史记录
   - 内容：每笔交易的详情（时间、币种、方向、数量、价格、盈亏等）
   - 由 strategy_bot.py 和 bot_server.py 写入
   - 由 web_ui.py 和 dashboard.py 读取展示

10. watchlist.json  — 自选币种列表
    - 内容：用户手动添加的关注币种数组 ["ETHUSDT", "BTCUSDT", ...]
    - 仪表盘首页展示这些币种的行情卡片

11. strategy_state.json  — 策略运行状态
    - 内容：策略引擎的状态快照（信号状态、延迟计时器等）
    - 由 strategy_bot.py 读写，用于崩溃恢复

12. strategy.log  — 策略引擎日志
    - 内容：strategy_bot.py 运行日志（信号判断、开平仓记录等）
    - 在 Web面板"系统日志"页可实时查看

13. bot.log  — 桥接器日志
    - 内容：bot_server.py 运行日志（订单接收、下单结果等）

14. requirements.txt  — Python 依赖
    - 内容：ccxt, python-dotenv, fastapi, uvicorn, paramiko

15. 交易头像.jpg  — 管理面板头像
    - Web UI 侧边栏显示的头像图片
